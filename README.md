# Chord Visualizer for Guitar #
## From your friends at Applied Hyperkinetics ##
A basic visualizer for voicing chords on the guitar. 

![main UI screenshot](img/main-ui.png)

## Voicing Notes ##
This visualizer uses a curated database of chord voicings for guitar from [tombatossal's chords-db project](https://github.com/tombatossals/chords-db) on github for common chord voicings. It also implements code which generates additional voicings beyond these common chord shapes. By default the UI displays only curated voicings; you can expand the set of displayed voicings by checking the "Include generated voicings" box, and further tune what generated voicings are displayed using the "Generated voicings Scope" drop-down. The "Common" setting shows generated voicings that fit a conservative fretting-hand playability filter. The "All" setting shows chord voicings which may be awkward or even impossible to finger.
